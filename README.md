# GPU 算力买 or 租 测算器

一个开箱即用的小工具，帮你判断：**这个算力需求该买卡，还是按需租用更划算？**

作者人设：AI Infra 解决方案架构师（小红书：「劝退GPU的架构师」）。

## 功能

- 输入 GPU 型号（A800/A100/H20/H100/4090/昇腾910B 一键预设）、卡数、负载率等参数
- 实时计算 **自建年成本 vs 租用年成本** 及差额
- 自动给出「买 or 租」结论 + 盈亏平衡负载率
- 负载率-年成本曲线图（可视化交叉点）
- 一键复制结论摘要（可直接发客户/发评论区）

## 计算口径

- **自建年成本** = 整机价 / 折旧年限 + 满载功耗 × 8760h × 电价 × 负载率 + 年运维费
- **租用年成本** = 卡时单价 × 卡数 × 8760h × 负载率（按需仅按实际占用付费，单价通常已含电费运维）
- **盈亏平衡负载率** = 自建固定成本 / 满负载租用年成本

> 价格为市场示意值，随行情波动，结果仅作决策参考，不构成采购建议。
